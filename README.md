# Ателье КЮН

Минимальный знак **КЮН** с расходящимися лучами для машинной вышивки на футболке.

## Открыть

После публикации на GitHub Pages:

**https://serega40in.github.io/kyun-atelier/**

Локально: откройте `index.html` в браузере (достаточно статики, без сборки).

## Возможности

- Композиции: **Корона**, **Знак** (ореол), **Солнце**
- Размещение: грудь / спина, перетаскивание, размер в см
- Цвет ткани и загрузка фото футболки
- Параметры букв и лучей, чередование нитей, камень в «Ю»
- Подсказки по толщине стежка
- Экспорт **SVG** (для программы вышивки) и **PNG**

## Стек

Чистый HTML / CSS / JS. Без сервера и сборки — подходит для GitHub Pages.
