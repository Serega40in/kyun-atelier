# Ателье КЮН — алхимическая лаборатория знака

Минимальный знак **КЮН** с расходящимися лучами для машинной вышивки на футболке.  
Теперь — лаборатория: несколько композиций, генерация, микс пресетов и тонкая работа с линией.

## Открыть

**https://serega40in.github.io/kyun-atelier/**

Локально: откройте `index.html` в браузере (статика, без сборки).

## Возможности

* Композиции: **Корона**, **Знак** (ореол), **Солнце**, **Атан ор** (новый алхимический знак с кольцом)
* Пресеты: Дзен, Свет, Колос, Солнце, Тишина, **Атан ор**, **Меркурий**
* **Лаборатория**: Мутация (тонкая вариация), Микс пресетов, Случайный знак
* Размещение: грудь / спина, перетаскивание, размер в см
* Цвет ткани и загрузка фото футболки
* Параметры букв и лучей, чередование нитей, камень в «Ю», кольцо
* Подсказки по толщине стежка
* Экспорт **SVG** (для программы вышивки) и **PNG**
* История (Undo/Redo), сохранение в localStorage

## Стек

Чистый HTML / CSS / JS. Без сервера и сборки — подходит для GitHub Pages.

## Знак «Атан ор»

Собственный синтез: полные солнечные лучи + алхимическое кольцо + камень в Ю.  
Идея — атан ор как сосуд превращения: слово остаётся, форма переплавляется.
